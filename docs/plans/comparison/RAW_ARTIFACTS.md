## Use Rules

- Use the `20260316-210134` benchmark directory as the current `iojournal` local benchmark source of record for Sprint 11D planning and Sprint 12 publication hardening.
- Use the `20260316-143805` benchmark directory as the source of record for the Sprint 11A file-sink `io_uring` accept or reject decision.
- Use the `20260316-145708` benchmark directory as the source of record for the Sprint 11A SIMD keep or drop decision.
- Use the `20260316-150320` benchmark directory as the current Tier 1 competitor source of record for the post-SIMD comparison handoff.
- Use the `20260316-210204` profiling directory as the active instruction-cost and repeatability source of record.
- Use the `20260316-210329`, `20260316-210345`, and `20260316-210349` profiling directories as the active `uftrace` wall-time companion sources for Sprint 11D handoff and Sprint 12 publication hardening.
- Keep older Sprint 09 runs for continuity and drift checks, not as the primary publication source.
- Do not cite analyzer or coverage artifacts as replacements for benchmark or profiler evidence.
